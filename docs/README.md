# Docs: which file holds what

Read `flutter-refactor.md` first (short). Then open only the one the task
needs: every file read costs tokens.

| File | Holds | Open it when |
|---|---|---|
| `flutter-refactor.md` | Where the refactor stands, what Ed hasn't seen yet, next steps | Every session |
| `how-we-work.md` | Ed's rules, builds, versions, the traps that have bitten | Before changing code |
| `cost.md` | Keeping sessions cheap: which model and which agent does what | Before a long or multi-part task |
| `code-map.md` | Which file holds what, and how big it is | Looking for something |
| `map.md` | Everything built on the map and how it works | Map work |
| `data-sources.md` | Every outside source: endpoint, licence, what was measured, dead ends | Adding or checking data |
| `decisions.md` | What Ed approved and rejected, in his words | Any visual or design choice |
| `upstream-whole-plate-blend.md` | A patch offered to the web page upstream | Web-page sync only |

Agents are in `.claude/agents/`, project skills in `.claude/skills/`
(their `README.md` also lists the plugin skills we use).
